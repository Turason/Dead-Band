Scenario Editor (JSON)

Edit the current chapter. Chapters are ordered in data/chapters.json and each points to a JSON file in data/. Include day, time, and weather. Add "features": {"dtmf": true} to reveal the DTMF keypad only in a chapter that introduces it. Mark the final response with "chapterComplete": true and "next": null to offer the next chapter. Station match can require radio or station settings; omitted fields are ignored. Stations may have beacon text for Listen, signalStrength from 0–10, and a dtmfSequences object mapping digit sequences to responses.
